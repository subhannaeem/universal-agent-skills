# WordPress Website Bundle

Build a complete, responsive, animated, accessible WordPress site.

| Skill | Role |
|---|---|
| `wp-build-complete-website` | Orchestrator: brief → build → checks → hand-over |
| `wp-animated-block-theme` | Scroll, hover and hero animation |
| `wp-responsive-fluid-design` | Fluid type and spacing |
| `wp-gsap-lottie-integration` | GSAP / Lottie, loaded safely |
| `wp-motion-performance-audit` | Finds animation that hurts speed |
| `wp-accessible-ui-review` | Contrast, focus, headings, reduced motion |

## Install (installs all 6 together)

```bash
./install.sh wordpress           # into this project
./install.sh wordpress --global  # into your home folder
```

## Use

> Use wp-build-complete-website to build a website for *<your business>*.

The skills must stay installed side by side: the orchestrator calls the other five.
