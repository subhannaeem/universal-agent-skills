# Site brief: Sunrise Bakery (example)

**Prompt:** "Build me a complete website for a small neighborhood bakery."

- **Purpose / audience:** show products and hours; local customers on phones.
- **Tone:** warm, friendly. **Colors:** cream `#fff8ef`, brown `#4a2c1a`, accent `#d9822b`. **Fonts:** system serif headings, system sans body.
- **Pages:** Home, Menu, About, Contact.
- **Features:** contact form (core block), opening hours, Instagram link. No shop.

## Assumptions (accept, reject or advise)
1. Block theme with core blocks only, no plugins.
2. Placeholder photos with descriptive `alt` text.
3. Scroll reveal on sections; hover lift on menu cards; all disabled for reduced motion.
4. Mobile-first, checked at 360 / 768 / 1024 / 1440 px.
